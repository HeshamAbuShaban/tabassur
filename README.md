# Tabassur | تَبَصُّر

An immersive contemplation app that takes you from the edges of galaxies to the inside of an atom.

Two journeys:

· الآفاق (The Horizons): Cosmic Web → Galaxies → Earth → Mountains → Oceans
· الأنفس (The Selves): Body → Heart → Cell → Nucleus → DNA → Atom

Free exploration. No forced timeline. No preset questions. Just you, the scene, and a verse at each station.

Built on real data: SDSS, NASA, NOAA, Allen Brain Atlas, Human Protein Atlas, RCSB PDB.

Guided by: ﴿سَنُرِيهِمْ آيَاتِنَا فِي الْآفَاقِ وَفِي أَنفُسِهِمْ﴾

---

Stack: Three.js (prototype) → Filament + Jetpack Compose (final)
Built with: Qwen Code
Target: 60 FPS on mid-range devices, ≤ 20 MB

---

No depiction of living beings. No visualization of the unseen. Quran and Hadith are never AI-generated. Every simulated scene is labeled.
